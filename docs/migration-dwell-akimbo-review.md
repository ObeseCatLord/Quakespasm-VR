# Dwell paired axes: architecture review and implementation boundary

An Astra source review found that Dwell's berserk axes are a larger vertical
than the Enyo SMGs. The installed Dwell 2.2 program is 820938 bytes with SHA-256
`fe7d21d4bdfd1a5e6672d1606efd774cb730d7f5b68941d82175596f22e719fd`.
Its `W_FireAxe` has first statement 14560 and calls `makevectors` at 14565,
then `traceline2` at 14578 and 14586. The `berserk_finished` field is present.
These facts were checked against the installed program under GDB; the review
also inspected the donor source. No Dwell port was made in this review.

| Recommendation | Disposition |
| --- | --- |
| Keep the existing model loader, private pair command, pose scope and contact transport. | **Adopt.** They remain the narrow owners; do not copy the donor's parallel akimbo context or add another protocol. |
| Enable the Dwell pair after only a pinned `makevectors` hook. | **Reject.** The donor's immersive paired axes also require two source-pinned cutting edges, the Dwell contact profile, QC helper trace filtering, and correct per-hand held transforms. A cosmetic or trigger-only path must be explicitly scoped and qualified before any offer. |
| Reuse the stock-axe one-shot contact handler as-is. | **Reject.** Dwell's `W_FireAxe → traceline2` helper can retry after acquisition; its accepted fraction and later misses need the donor's scoped helper semantics. Calling the native swing scheduler again can duplicate a delayed strike. |
| Apply the generic dominant-hand origin before Dwell QuakeC runs. | **Reject.** The donor defers paired pose mutation until Dwell's pinned strike, preserving earlier QuakeC observations and scope restoration. |
| Implement Dwell next as a single small slice. | **Defer.** Sequence the held/edge transforms, paired contact admission, QC helper/outcome adapter and live parity proof together, then enable the offer. The smaller next user-visible slice is QBJ3 shotgun wrist-roll preservation. |

The installed Dwell desktop map entered gameplay without an OpenXR runtime.
That startup check does not establish firing or immersive melee equivalence.
The Dwell pair capability and melee profile remain off on `2.0` until the
complete admitted behavior is present. Physical headset checks remain with
the user; Windows and ARM qualification remain later release gates.

## Held geometry review

A subsequent Astra xhigh review chose an adapter at the existing pair matrix
and hand-angle owners. The pinned Dwell 2.2 `v_axeb.mdl` has 106284 bytes and
CRC32 `69c2bf5e`. The existing splitter verifies that source and produces
70284-byte left/right halves with CRC32 `8e5fd44b`/`f3c035b6`. The recipe's
decoded `source_anchors` invert to raw MDL grip centroids
`{132.75, 176.125, 109.75}` and `{144.875, 122.25, 109.125}`. They are
exactly the donor's eight-vertex palm averages; no new grip fields or retained
pose buffer are needed. The generated halves' frame-zero cutting edges are
raw vertices 54/72: left `{76,178,59}`→`{51,183,68}` and right
`{77,117,71}`→`{52,114,83}`.

| Recommendation | Disposition |
| --- | --- |
| Reuse recipe anchors for Dwell grip centering and a small immutable edge table. | **Adopt.** Decode each anchor through the pinned MDL scale/origin, then use the existing held-model matrix with local translation `−scale × raw_grip`. This replaces Dwell's ordinary offset and left-residual reflection while preserving the user's held scale. |
| Retain every Dwell source pose or create another render path. | **Reject.** The source-pinned ready-pose vertices suffice for the two physical edges. Keep the ordinary vkQuake alias renderer. |
| Trust half-model path names as proof of generated bytes. | **Reject.** A failed split can leave a file-backed half or a cached model. Record per-load generated provenance and require it for Dwell admission. CRC is a compatibility fingerprint, not authentication. |
| Copy the source viewmodel's animation state to the fixed held axes. | **Change.** Pin both half-model poses to the ready frame while leaving the canonical source animation untouched; otherwise interpolation can blend a different QC frame. |
| Apply the donor's hand correction independently in view and input. | **Reject.** One shared angle selector must serve presentation and body-space contact; wire angles stay physical and hand indices stay anatomical. |

This geometry adapter is not a Dwell gameplay offer. The client currently
accepts only one immersive contact hand, pending contact identity stores one
device, and the server admits only the stock-axe profile. Paired contact and
the Dwell QuakeC trace helper/outcome adapter remain required before the offer
can be enabled. A future end-to-end proof must compare both hands, dominance,
combined wrist rotations, nonunit held scale, visible edge alignment, wall
response and the exact-once native damage outcome.
