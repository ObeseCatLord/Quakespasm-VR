# Ravenkeep AD shadow-axe VR calibration

The installed Ravenkeep `progs/v_shadaxe0.mdl` through
`v_shadaxe5.mdl` match the Arcane Dimensions model bytes. This profile
replaces only those six held transforms with AD's existing scale, held offset
and muzzle offset. Ravenkeep's other weapon entries stay as authored for its
different models.

Copy `vr_weapons.txt` to the Ravenkeep game directory to use it. The game's
own file remains authoritative for later user calibration edits.
